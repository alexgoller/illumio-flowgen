# flowgen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single Rust binary `flowgen` that generates realistic NetFlow v5 / v9 / IPFIX traffic over UDP for Illumio Flowlink demos and testing, packaged for Linux and macOS by GitHub Actions.

**Architecture:** Library crate (`src/lib.rs`) with focused modules: `model` (protocol-neutral `FlowRecord`), `export` (one encoder per protocol behind an `Encoder` trait), `config` (TOML scenario + CLI overrides + validation), `pattern` (host sampling, weighted rules, scans, rate shapes), `presets`, `stats`, `ui` (indicatif progress / plain logs / summary), `sender` (100 ms tick loop + UDP / dry-run sink) and `cli` (clap). `src/main.rs` only maps errors to exit code 2. Packaging lives in `scripts/` and `.github/workflows/`, and only runs in CI.

**Tech Stack:** Rust (edition 2024, stable ≥ 1.88 for let-chains; local toolchain is 1.97), clap 4.6, serde 1, toml 1, anyhow 1, rand 0.10, ipnet 2.12, humantime 2.4, ctrlc 3.5, indicatif 0.18. Dev: netflow_parser 1.0.6 (feature `netflow_common`). CI: GitHub Actions, cargo-deb, cargo-generate-rpm, pkgbuild, lipo.

**Spec:** `docs/superpowers/specs/2026-10-20-flowgen-design.md`

## Global Constraints

- Export protocols: NetFlow v5, NetFlow v9 (RFC 3954), IPFIX (RFC 7011); UDP only; IPv4 only.
- Default collector ports when `--collector` has no port: 2055 for v5/v9, 4739 for IPFIX.
- v9/IPFIX template ID 256; template resent every `template_refresh_secs` (default 30) or every 100 packets, whichever comes first.
- `max_datagram` default 1400, valid range 256..=65000.
- Records use wall-clock time: end = now, duration random 0.1–30 s.
- Multicast (224.0.0.0/4) in any rule/scan is a validation error; `flows_per_sec` > 5000 is a warning.
- Every startup error prints `flowgen: error: <message>` to stderr and exits with code 2.
- Progress bars, stats, warnings and summary go to **stderr**; dry-run flow lines go to **stdout**.
- Presets have no collector and cover ≤ 60 host IPs each.
- `flowgen ips` refuses scenarios with more than 4096 hosts unless `--all` is given.
- **Packages are built only in GitHub Actions — never build packages locally.** No Homebrew, no code signing/notarization.
- rand 0.10 API: `use rand::{RngExt, SeedableRng}; use rand::rngs::StdRng; use rand::seq::IndexedRandom;` — methods are `random_range`, `random_bool`, `choose`.
- netflow_parser API (tests only): `NetflowParser::default().parse_bytes(&buf) -> ParseResult { packets, error }`; `parse_bytes_as_netflow_common_flowsets(&buf) -> (Vec<NetflowCommonFlowSet>, Option<NetflowError>)`. Reuse one parser instance across datagrams so v9/IPFIX templates are remembered.

## Review Focus

1. **Collector port closed or host unreachable** — the run must keep going until `--duration`, count send errors, warn at most once per stats interval, and exit 0 (Task 9 test `closed_port_does_not_abort`).
2. **Dry-run piped into `head`** (broken pipe on stdout) — must stop quietly with exit 0, not panic or error (Task 9 test `dry_run_broken_pipe_stops_cleanly`).
3. **Huge CIDRs such as `10.0.0.0/8`** — sampling must be arithmetic (no host enumeration, no big allocation); `ips` must refuse without `--all` (Task 6 tests `host_pool_samples_large_net_without_enumerating`, `scenario_hosts_respects_limit`).
4. **Fractional or zero rates, scan-only scenarios** — 0.5 flows/s must yield flows over time via carry; rate 0 with only `[[scan]]` must still emit bursts (Task 6 tests `pacer_carries_fractions`, `scan_only_scenario_emits_bursts`).
5. **More records than fit one datagram, small `max_datagram`** — every datagram ≤ limit and a fresh collector can decode the first one (template included) (Task 3/4 tests `*_splits_and_stays_under_limit`).

```rust
//! Protocol-neutral flow record shared by generators and encoders.

use std::net::Ipv4Addr;
use std::time::{SystemTime, UNIX_EPOCH};

pub const PROTO_ICMP: u8 = 1;
pub const PROTO_TCP: u8 = 6;
pub const PROTO_UDP: u8 = 17;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct FlowRecord {
    pub src_addr: Ipv4Addr,
    pub dst_addr: Ipv4Addr,
    pub src_port: u16,
    pub dst_port: u16,
    pub protocol: u8,
    pub packets: u64,
    pub bytes: u64,
    pub tcp_flags: u8,
    pub start: SystemTime,
    pub end: SystemTime,
}

impl FlowRecord {
    /// One-line human form used by `--dry-run`.
    pub fn dry_run_line(&self) -> String {
        format!(
            "{} {}:{} -> {}:{} pkts={} bytes={}",
            proto_name(self.protocol),
            self.src_addr,
            self.src_port,
            self.dst_addr,
            self.dst_port,
            self.packets,
            self.bytes
        )
    }
}

pub fn proto_name(protocol: u8) -> String {
    match protocol {
        PROTO_ICMP => "icmp".to_string(),
        PROTO_TCP => "tcp".to_string(),
        PROTO_UDP => "udp".to_string(),
        other => format!("proto-{other}"),
    }
}

/// Milliseconds since the Unix epoch; times before the epoch clamp to 0.
pub fn unix_millis(t: SystemTime) -> u64 {
    t.duration_since(UNIX_EPOCH)
        .map(|d| d.as_millis() as u64)
        .unwrap_or(0)
}
```

```rust
//! Flow export encoders. Each encoder turns `FlowRecord`s into UDP payloads.

pub mod v5;

use std::time::{Duration, SystemTime};

use serde::Deserialize;

use crate::model::FlowRecord;

/// Pretend the exporter booted this long before flowgen started, so
/// sysUptime-relative flow start times never underflow.
pub const BOOT_OFFSET: Duration = Duration::from_secs(3600);

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, Deserialize, clap::ValueEnum)]
#[serde(rename_all = "lowercase")]
pub enum Protocol {
    V5,
    V9,
    #[default]
    Ipfix,
}

impl Protocol {
    /// Port used when the collector is given without one (Flowlink docs: 2055 NetFlow, 4739 IPFIX).
    pub fn default_port(self) -> u16 {
        match self {
            Protocol::V5 | Protocol::V9 => 2055,
            Protocol::Ipfix => 4739,
        }
    }

    pub fn label(self) -> &'static str {
        match self {
            Protocol::V5 => "NetFlow v5",
            Protocol::V9 => "NetFlow v9",
            Protocol::Ipfix => "IPFIX",
        }
    }
}

pub trait Encoder {
    /// Encode records into one or more datagrams, each <= the configured max size.
    /// `now` is the export time. Encoders own sequence numbers and template state.
    fn encode(&mut self, records: &[FlowRecord], now: SystemTime) -> Vec<Vec<u8>>;
}

pub(crate) fn put_u8(buf: &mut Vec<u8>, v: u8) {
    buf.push(v);
}

pub(crate) fn put_u16(buf: &mut Vec<u8>, v: u16) {
    buf.extend_from_slice(&v.to_be_bytes());
}

pub(crate) fn put_u32(buf: &mut Vec<u8>, v: u32) {
    buf.extend_from_slice(&v.to_be_bytes());
}

pub(crate) fn put_u64(buf: &mut Vec<u8>, v: u64) {
    buf.extend_from_slice(&v.to_be_bytes());
}

/// Saturating u64 -> u32 for 32-bit counters.
pub(crate) fn sat_u32(v: u64) -> u32 {
    u32::try_from(v).unwrap_or(u32::MAX)
}

/// Milliseconds between `boot` and `t` (0 if `t` is before boot), wrapping like a router uptime.
pub(crate) fn uptime_ms(boot: SystemTime, t: SystemTime) -> u32 {
    t.duration_since(boot).unwrap_or_default().as_millis() as u32
}
```

```rust
//! NetFlow v5: fixed 24-byte header + up to 30 fixed 48-byte records.

use std::time::{SystemTime, UNIX_EPOCH};

use super::{Encoder, put_u8, put_u16, put_u32, sat_u32, uptime_ms};
use crate::model::FlowRecord;

const HEADER_LEN: usize = 24;
const RECORD_LEN: usize = 48;
const MAX_RECORDS: usize = 30;

pub struct V5Encoder {
    boot: SystemTime,
    max_datagram: usize,
    flow_sequence: u32,
}

impl V5Encoder {
    pub fn new(boot: SystemTime, max_datagram: usize) -> Self {
        Self { boot, max_datagram, flow_sequence: 0 }
    }
}

impl Encoder for V5Encoder {
    fn encode(&mut self, records: &[FlowRecord], now: SystemTime) -> Vec<Vec<u8>> {
        let per_packet = (self.max_datagram.saturating_sub(HEADER_LEN) / RECORD_LEN).clamp(1, MAX_RECORDS);
        let epoch = now.duration_since(UNIX_EPOCH).unwrap_or_default();
        let mut out = Vec::new();
        for chunk in records.chunks(per_packet) {
            let mut buf = Vec::with_capacity(HEADER_LEN + chunk.len() * RECORD_LEN);
            put_u16(&mut buf, 5);
            put_u16(&mut buf, chunk.len() as u16);
            put_u32(&mut buf, uptime_ms(self.boot, now));
            put_u32(&mut buf, epoch.as_secs() as u32);
            put_u32(&mut buf, epoch.subsec_nanos());
            put_u32(&mut buf, self.flow_sequence);
            put_u8(&mut buf, 0); // engine type
            put_u8(&mut buf, 0); // engine id
            put_u16(&mut buf, 0); // sampling interval
            for r in chunk {
                put_u32(&mut buf, r.src_addr.into());
                put_u32(&mut buf, r.dst_addr.into());
                put_u32(&mut buf, 0); // next hop
                put_u16(&mut buf, 0); // input ifindex
                put_u16(&mut buf, 0); // output ifindex
                put_u32(&mut buf, sat_u32(r.packets));
                put_u32(&mut buf, sat_u32(r.bytes));
                put_u32(&mut buf, uptime_ms(self.boot, r.start));
                put_u32(&mut buf, uptime_ms(self.boot, r.end));
                put_u16(&mut buf, r.src_port);
                put_u16(&mut buf, r.dst_port);
                put_u8(&mut buf, 0); // pad1
                put_u8(&mut buf, r.tcp_flags);
                put_u8(&mut buf, r.protocol);
                put_u8(&mut buf, 0); // tos
                put_u16(&mut buf, 0); // src as
                put_u16(&mut buf, 0); // dst as
                put_u8(&mut buf, 0); // src mask
                put_u8(&mut buf, 0); // dst mask
                put_u16(&mut buf, 0); // pad2
            }
            self.flow_sequence = self.flow_sequence.wrapping_add(chunk.len() as u32);
            out.push(buf);
        }
        out
    }
}
```

```rust
pub const TEMPLATE_ID: u16 = 256;
pub const TEMPLATE_EVERY_PACKETS: u32 = 100;

#[derive(Debug, Clone, Copy)]
pub struct EncoderOptions {
    /// v9 source id / IPFIX observation domain id.
    pub observation_domain: u32,
    pub template_refresh: Duration,
    pub max_datagram: usize,
}

/// Decides when a v9/IPFIX packet must carry the template:
/// first packet, then every `interval` or every 100 packets, whichever comes first.
pub(crate) struct TemplateTimer {
    interval: Duration,
    last: Option<SystemTime>,
    packets_since: u32,
}

impl TemplateTimer {
    pub(crate) fn new(interval: Duration) -> Self {
        Self { interval, last: None, packets_since: 0 }
    }

    /// Call once per outgoing packet; returns whether it must include the template.
    pub(crate) fn due(&mut self, now: SystemTime) -> bool {
        let due = match self.last {
            None => true,
            Some(last) => {
                self.packets_since >= TEMPLATE_EVERY_PACKETS
                    || match now.duration_since(last) {
                        Ok(age) => age >= self.interval,
                        Err(_) => true, // clock jumped backwards: resend
                    }
            }
        };
        if due {
            self.last = Some(now);
            self.packets_since = 0;
        }
        self.packets_since += 1;
        due
    }
}
```

```rust
//! NetFlow v9 (RFC 3954): one template (ID 256) + data FlowSets padded to 32 bits.

use std::time::{SystemTime, UNIX_EPOCH};

use super::{
    Encoder, EncoderOptions, TEMPLATE_ID, TemplateTimer, put_u8, put_u16, put_u32, put_u64,
    uptime_ms,
};
use crate::model::FlowRecord;

const HEADER_LEN: usize = 20;
/// (field type, length): IN_BYTES, IN_PKTS, PROTOCOL, TCP_FLAGS, L4_SRC_PORT,
/// IPV4_SRC_ADDR, L4_DST_PORT, IPV4_DST_ADDR, FIRST_SWITCHED, LAST_SWITCHED.
const FIELDS: [(u16, u16); 10] = [
    (1, 8),
    (2, 8),
    (4, 1),
    (6, 1),
    (7, 2),
    (8, 4),
    (11, 2),
    (12, 4),
    (22, 4),
    (21, 4),
];
const RECORD_LEN: usize = 38;
const TEMPLATE_SET_LEN: usize = 4 + 4 + FIELDS.len() * 4;
const SET_HEADER_LEN: usize = 4;
const MAX_PADDING: usize = 3;

pub struct V9Encoder {
    boot: SystemTime,
    source_id: u32,
    max_datagram: usize,
    sequence: u32,
    templates: TemplateTimer,
}

impl V9Encoder {
    pub fn new(boot: SystemTime, opts: &EncoderOptions) -> Self {
        Self {
            boot,
            source_id: opts.observation_domain,
            max_datagram: opts.max_datagram,
            sequence: 0,
            templates: TemplateTimer::new(opts.template_refresh),
        }
    }
}

impl Encoder for V9Encoder {
    fn encode(&mut self, records: &[FlowRecord], now: SystemTime) -> Vec<Vec<u8>> {
        let epoch_secs = now.duration_since(UNIX_EPOCH).unwrap_or_default().as_secs() as u32;
        let mut out = Vec::new();
        let mut rest = records;
        while !rest.is_empty() {
            let with_template = self.templates.due(now);
            let overhead = HEADER_LEN
                + if with_template { TEMPLATE_SET_LEN } else { 0 }
                + SET_HEADER_LEN
                + MAX_PADDING;
            let n = (self.max_datagram.saturating_sub(overhead) / RECORD_LEN)
                .max(1)
                .min(rest.len());
            let (chunk, tail) = rest.split_at(n);
            rest = tail;

            let mut buf = Vec::with_capacity(self.max_datagram);
            put_u16(&mut buf, 9);
            put_u16(&mut buf, (n + usize::from(with_template)) as u16);
            put_u32(&mut buf, uptime_ms(self.boot, now));
            put_u32(&mut buf, epoch_secs);
            put_u32(&mut buf, self.sequence);
            put_u32(&mut buf, self.source_id);

            if with_template {
                put_u16(&mut buf, 0); // template FlowSet id
                put_u16(&mut buf, TEMPLATE_SET_LEN as u16);
                put_u16(&mut buf, TEMPLATE_ID);
                put_u16(&mut buf, FIELDS.len() as u16);
                for (ty, len) in FIELDS {
                    put_u16(&mut buf, ty);
                    put_u16(&mut buf, len);
                }
            }

            let set_len = SET_HEADER_LEN + n * RECORD_LEN;
            let padded = set_len.div_ceil(4) * 4;
            put_u16(&mut buf, TEMPLATE_ID);
            put_u16(&mut buf, padded as u16);
            for r in chunk {
                put_u64(&mut buf, r.bytes);
                put_u64(&mut buf, r.packets);
                put_u8(&mut buf, r.protocol);
                put_u8(&mut buf, r.tcp_flags);
                put_u16(&mut buf, r.src_port);
                put_u32(&mut buf, r.src_addr.into());
                put_u16(&mut buf, r.dst_port);
                put_u32(&mut buf, r.dst_addr.into());
                put_u32(&mut buf, uptime_ms(self.boot, r.start));
                put_u32(&mut buf, uptime_ms(self.boot, r.end));
            }
            buf.resize(buf.len() + (padded - set_len), 0);

            self.sequence = self.sequence.wrapping_add(1);
            out.push(buf);
        }
        out
    }
}
```

```rust
impl PortSpec {
    pub fn expand(&self) -> Result<Vec<u16>> {
        match self {
            PortSpec::List(ports) => Ok(ports.clone()),
            PortSpec::Range(spec) => {
                let spec = spec.trim();
                let (lo, hi) = spec.split_once('-').unwrap_or((spec, spec));
                let parse = |s: &str| -> Result<u16> {
                    s.trim().parse().with_context(|| format!("invalid port range '{spec}'"))

                    bail!("invalid port range '{spec}' (expected 1 <= start <= end)");

            }
        }
    }

            bail!("rate.period_secs must be > 0 for shape = \"sine\"");
        }
        if !(0.0..=1.0).contains(&r.amplitude) {
            bail!("rate.amplitude must be between 0 and 1, got {}", r.amplitude);
        }
        if !(0.0..=1.0).contains(&r.burst_chance) {
            bail!("rate.burst_chance must be between 0 and 1, got {}", r.burst_chance);
        }
        if r.burst_multiplier < 1.0 || r.burst_secs <= 0.0 {
            bail!("rate.burst_multiplier must be >= 1 and rate.burst_secs > 0");
        }

        for rule in &self.rules {
            let ctx = format!("rule '{}'", rule.name);
            if rule.src.is_empty() || rule.dst.is_empty() {
                bail!("{ctx}: src and dst must not be empty");

            if rule.weight == 0 {
                bail!("{ctx}: weight must be > 0");

                    warnings.push(format!("{ctx}: dst_ports are ignored for icmp"));

                Proto::Tcp | Proto::Udp if rule.dst_ports.is_empty() => {
                    bail!("{ctx}: dst_ports must not be empty for tcp/udp");

                _ => {}
            }

                if let Some([lo, hi]) = range
                    && (lo == 0 || lo > hi)
                {
                    bail!("{ctx}: {field} must be [min, max] with 1 <= min <= max");
                }
            }
        }

        for (i, scan) in self.scans.iter().enumerate() {
            let ctx = format!("scan #{}", i + 1);
            if scan.dst.is_empty() {
                bail!("{ctx}: dst must not be empty");

                bail!("{ctx}: every_secs and flows_per_burst must be > 0");
            }
        }
        Ok(warnings)
    }
}

fn check_multicast<'a>(ctx: &str, nets: impl Iterator<Item = &'a Ipv4Net>) -> Result<()> {
    for net in nets {
        if overlaps_multicast(net) {
            bail!("{ctx}: {net} overlaps multicast range 224.0.0.0/4, which Flowlink ignores");
        }
    }
    Ok(())
}

pub fn overlaps_multicast(net: &Ipv4Net) -> bool {
    let lo = u32::from(net.network());
    let hi = u32::from(net.broadcast());
    lo <= u32::from(Ipv4Addr::new(239, 255, 255, 255)) && hi >= u32::from(Ipv4Addr::new(224, 0, 0, 0))
}

/// Parse "a.b.c.d/len" (host bits cleared) or a bare "a.b.c.d" (as /32).
pub fn parse_net(s: &str) -> Result<Ipv4Net> {
    let s = s.trim();
    if s.contains('/') {
        let net: Ipv4Net = s.parse().with_context(|| format!("invalid IPv4 CIDR '{s}'"))?;
        Ok(net.trunc())
    } else {
        let addr: Ipv4Addr = s.parse().with_context(|| format!("invalid IPv4 address '{s}'"))?;
        Ok(Ipv4Net::from(addr))
    }
}

fn de_nets<'de, D: Deserializer<'de>>(d: D) -> Result<Vec<Ipv4Net>, D::Error> {
    let raw = Vec::<String>::deserialize(d)?;
    raw.iter()
        .map(|s| parse_net(s).map_err(|e| serde::de::Error::custom(format!("{e:#}"))))
        .collect()
}

/// "host:port" -> (host, Some(port)); anything else -> (spec, None).
pub fn split_host_port(spec: &str) -> (&str, Option<u16>) {
    match spec.rsplit_once(':') {
        Some((host, port)) => match port.parse() {
            Ok(port) => (host, Some(port)),
            Err(_) => (spec, None),
        },
        None => (spec, None),
    }
}

/// Resolve the collector once; missing port defaults by protocol (2055 / 4739).
pub fn resolve_collector(spec: &str, protocol: Protocol) -> Result<SocketAddr> {
    let (host, port) = split_host_port(spec.trim());
    let port = port.unwrap_or_else(|| protocol.default_port());
    (host, port)
        .to_socket_addrs()
        .with_context(|| format!("cannot resolve collector '{host}'"))?
        .find(SocketAddr::is_ipv4)
        .with_context(|| format!("collector '{host}' has no IPv4 address"))
}
```

```rust
//! Flow generation: host sampling, weighted rules, port scans and rate shapes.

use std::collections::BTreeSet;
use std::f64::consts::TAU;
use std::net::Ipv4Addr;
use std::ops::RangeInclusive;
use std::time::{Duration, SystemTime};

use anyhow::{Result, bail};
use ipnet::Ipv4Net;
use rand::rngs::StdRng;
use rand::seq::IndexedRandom;
use rand::{RngExt, SeedableRng};

use crate::config::{Proto, Rate, Scenario, Shape};
use crate::model::{FlowRecord, PROTO_ICMP, PROTO_TCP};

const EPHEMERAL_PORTS: RangeInclusive<u16> = 32768..=60999;
const TCP_FLAGS_SESSION: u8 = 0x1b; // FIN|SYN|PSH|ACK
const TCP_FLAGS_SYN: u8 = 0x02;
const FLOW_DURATION_MS: RangeInclusive<u64> = 100..=30_000;
const SCAN_BYTES: RangeInclusive<u64> = 44..=60;
pub const IPS_LIMIT: u64 = 4096;

/// Seeded RNG; picks (and returns) a random seed when none is given so runs can be reproduced.
pub fn make_rng(seed: Option<u64>) -> (StdRng, u64) {
    let seed = seed.unwrap_or_else(rand::random::<u64>);
    (StdRng::seed_from_u64(seed), seed)
}

/// Uniform host sampling over a list of CIDRs without enumerating them.
#[derive(Debug, Clone)]
pub struct HostPool {
    /// (first host as u32, host count)
    ranges: Vec<(u32, u64)>,
    total: u64,
}

impl HostPool {
    pub fn new(nets: &[Ipv4Net]) -> Self {
        let ranges: Vec<(u32, u64)> = nets
            .iter()
            .map(|net| {
                let base = u32::from(net.network());
                match net.prefix_len() {
                    32 => (base, 1),
                    31 => (base, 2),
                    len => (base + 1, (1u64 << (32 - len)) - 2),
                }
            })
            .collect();
        let total = ranges.iter().map(|r| r.1).sum();
        Self { ranges, total }
    }

    pub fn len(&self) -> u64 {
        self.total
    }

    pub fn is_empty(&self) -> bool {
        self.total == 0
    }

    pub fn sample(&self, rng: &mut StdRng) -> Ipv4Addr {
        let mut i = rng.random_range(0..self.total);
        for &(first, count) in &self.ranges {
            if i < count {
                return Ipv4Addr::from(first + i as u32);
            }
            i -= count;
        }
        unreachable!("sample index is below total")
    }

    pub fn iter(&self) -> impl Iterator<Item = Ipv4Addr> + '_ {
        self.ranges
            .iter()
            .flat_map(|&(first, count)| (0..count).map(move |i| Ipv4Addr::from(first + i as u32)))
    }
}

/// Target flows/s over time.
pub struct RateShape {
    cfg: Rate,
    next_burst_check: f64,
    burst_until: f64,
}

impl RateShape {
    pub fn new(cfg: &Rate) -> Self {
        Self { cfg: cfg.clone(), next_burst_check: 1.0, burst_until: f64::NEG_INFINITY }
    }

    pub fn rate_at(&mut self, t: f64, rng: &mut StdRng) -> f64 {
        let c = &self.cfg;
        let base = c.flows_per_sec;
        let rate = match c.shape {
            Shape::Constant => base,
            Shape::Sine => base * (1.0 + c.amplitude * (TAU * t / c.period_secs).sin()),
            Shape::Burst => {
                while self.next_burst_check <= t {
                    if rng.random_bool(c.burst_chance) {
                        self.burst_until = self.next_burst_check + c.burst_secs;
                    }
                    self.next_burst_check += 1.0;
                }
                if t < self.burst_until { base * c.burst_multiplier } else { base }
            }
        };
        rate.max(0.0)
    }
}

/// Converts a rate into whole flows per tick, carrying the fractional remainder.
#[derive(Debug, Default)]
pub struct Pacer {
    carry: f64,
}

impl Pacer {
    pub fn due(&mut self, rate: f64, dt_secs: f64) -> usize {
        self.carry += rate * dt_secs;
        let n = self.carry.floor();
        self.carry -= n;
        n as usize
    }
}

pub struct ScanBurst {
    pub src: Ipv4Addr,
    pub flows: Vec<FlowRecord>,
}

struct CompiledRule {
    src: HostPool,
    dst: HostPool,
    protocol: u8,
    ports: Vec<u16>,
    packets: (u64, u64),
    bytes_per_packet: (u64, u64),
}

struct CompiledScan {
    src: Ipv4Addr,
    dst: HostPool,
    ports: Vec<u16>,
    every: Duration,
    flows_per_burst: u32,
    next_at: Duration,
}

pub struct Generator {
    rng: StdRng,
    rule_names: Vec<String>,
    rules: Vec<CompiledRule>,
    /// Running sum of weights, for weighted rule selection.
    cumulative: Vec<u64>,
    scans: Vec<CompiledScan>,
}

fn default_sizes(proto: Proto) -> ((u64, u64), (u64, u64)) {
    match proto {
        Proto::Tcp => ((5, 200), (60, 1400)),
        Proto::Udp => ((1, 20), (60, 1200)),
        Proto::Icmp => ((1, 4), (84, 84)),
    }
}

impl Generator {
    pub fn new(s: &Scenario, rng: StdRng) -> Result<Self> {
        let rules = s
            .rules
            .iter()
            .map(|r| {
                let (packets, bpp) = default_sizes(r.proto);
                CompiledRule {
                    src: HostPool::new(&r.src),
                    dst: HostPool::new(&r.dst),
                    protocol: r.proto.number(),
                    ports: if r.proto == Proto::Icmp { vec![0] } else { r.dst_ports.clone() },
                    packets: r.packets.map_or(packets, |[lo, hi]| (lo, hi)),
                    bytes_per_packet: r.bytes_per_packet.map_or(bpp, |[lo, hi]| (lo, hi)),
                }
            })
            .collect();
        let cumulative = s
            .rules
            .iter()
            .scan(0u64, |acc, r| {
                *acc += u64::from(r.weight);
                Some(*acc)
            })
            .collect();
        let scans = s
            .scans
            .iter()
            .map(|sc| {
                let every = Duration::from_secs(sc.every_secs);
                Ok(CompiledScan {
                    src: sc.src,
                    dst: HostPool::new(&sc.dst),
                    ports: sc.ports.expand()?,
                    every,
                    flows_per_burst: sc.flows_per_burst,
                    next_at: every,
                })
            })
            .collect::<Result<_>>()?;
        Ok(Self {
            rng,
            rule_names: s.rules.iter().map(|r| r.name.clone()).collect(),
            rules,
            cumulative,
            scans,
        })
    }

    pub fn rule_names(&self) -> &[String] {
        &self.rule_names
    }

    pub fn has_rules(&self) -> bool {
        !self.rules.is_empty()
    }

    pub fn rng(&mut self) -> &mut StdRng {
        &mut self.rng
    }

    /// One flow from a weighted-random rule. Panics if the scenario has no rules.
    pub fn next_flow(&mut self, now: SystemTime) -> (usize, FlowRecord) {
        let total = *self.cumulative.last().expect("next_flow requires at least one rule");
        let x = self.rng.random_range(0..total);
        let idx = self.cumulative.partition_point(|&c| c <= x);
        let rule = &self.rules[idx];
        let rng = &mut self.rng;

        let packets = rng.random_range(rule.packets.0..=rule.packets.1);
        let bytes = packets * rng.random_range(rule.bytes_per_packet.0..=rule.bytes_per_packet.1);
        let duration = Duration::from_millis(rng.random_range(FLOW_DURATION_MS));
        let record = FlowRecord {
            src_addr: rule.src.sample(rng),
            dst_addr: rule.dst.sample(rng),
            src_port: if rule.protocol == PROTO_ICMP { 0 } else { rng.random_range(EPHEMERAL_PORTS) },
            dst_port: *rule.ports.choose(rng).expect("validated: ports not empty"),
            protocol: rule.protocol,
            packets,
            bytes,
            tcp_flags: if rule.protocol == PROTO_TCP { TCP_FLAGS_SESSION } else { 0 },
            start: now - duration,
            end: now,
        };
        (idx, record)
    }

    /// All scan bursts due at `elapsed` since start (first burst after one interval).
    pub fn due_scans(&mut self, elapsed: Duration, now: SystemTime) -> Vec<ScanBurst> {
        let mut out = Vec::new();
        for scan in &mut self.scans {
            while elapsed >= scan.next_at {
                scan.next_at += scan.every;
                let flows = (0..scan.flows_per_burst)
                    .map(|_| FlowRecord {
                        src_addr: scan.src,
                        dst_addr: scan.dst.sample(&mut self.rng),
                        src_port: self.rng.random_range(EPHEMERAL_PORTS),
                        dst_port: *scan.ports.choose(&mut self.rng).expect("validated: ports not empty"),
                        protocol: PROTO_TCP,
                        packets: 1,
                        bytes: self.rng.random_range(SCAN_BYTES),
                        tcp_flags: TCP_FLAGS_SYN,
                        start: now,
                        end: now,
                    })
                    .collect();
                out.push(ScanBurst { src: scan.src, flows });
            }
        }
        out
    }
}

/// Every host IP the scenario can emit (sorted, deduplicated), for creating
/// matching unmanaged workloads in the PCE. `limit` caps the pre-dedup count.
pub fn scenario_hosts(s: &Scenario, limit: Option<u64>) -> Result<Vec<Ipv4Addr>> {
    let mut pools = Vec::new();
    for r in &s.rules {
        pools.push(HostPool::new(&r.src));
        pools.push(HostPool::new(&r.dst));
    }
    for sc in &s.scans {
        pools.push(HostPool::new(&sc.dst));
    }
    let upper = pools.iter().map(HostPool::len).sum::<u64>() + s.scans.len() as u64;
    if let Some(limit) = limit
        && upper > limit
    {
        bail!("scenario covers up to {upper} host IPs (limit {limit}); pass --all to list them anyway");
    }
    let mut hosts = BTreeSet::new();
    for pool in &pools {
        hosts.extend(pool.iter());
    }
    hosts.extend(s.scans.iter().map(|sc| sc.src));
    Ok(hosts.into_iter().collect())
}
```

```rust
//! Run counters plus a short sliding window for the measured flow rate.

use std::collections::VecDeque;
use std::time::{Duration, Instant};

const WINDOW: Duration = Duration::from_secs(5);

#[derive(Debug, Default)]
pub struct Stats {
    pub flows: u64,
    pub datagrams: u64,
    pub wire_bytes: u64,
    pub send_errors: u64,
    pub scan_bursts: u64,
    pub scan_flows: u64,
    pub per_rule: Vec<u64>,
    pub target_rate: f64,
    window: VecDeque<(Instant, u64)>,
}

impl Stats {
    pub fn new(rule_count: usize) -> Self {
        Self { per_rule: vec![0; rule_count], ..Self::default() }
    }

    /// Record the current flow total at `now`; drops samples older than the window.
    pub fn sample(&mut self, now: Instant) {
        self.window.push_back((now, self.flows));
        while let Some(&(t, _)) = self.window.front() {
            if now.duration_since(t) > WINDOW {
                self.window.pop_front();
            } else {
                break;
            }
        }
    }

    /// Flows per second over the sampled window (0 with fewer than two samples).
    pub fn measured_rate(&self) -> f64 {
        match (self.window.front(), self.window.back()) {
            (Some(&(t0, f0)), Some(&(t1, f1))) if t1 > t0 => {
                (f1 - f0) as f64 / (t1 - t0).as_secs_f64()
            }
            _ => 0.0,
        }
    }
}
```

```rust
//! Terminal output: header, live progress (indicatif), plain log lines and summary.
//! Everything goes to stderr so dry-run output on stdout stays pipeable.

use std::io::IsTerminal;
use std::net::SocketAddr;
use std::time::{Duration, Instant};

use indicatif::{ProgressBar, ProgressDrawTarget, ProgressStyle};

use crate::export::Protocol;
use crate::stats::Stats;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Mode {
    /// Progress bar / spinner with a live status line.
    Interactive,
    /// One stats line per interval, for logs and pipes.
    Plain,
    /// Only warnings and the final summary.
    Quiet,
}

pub fn pick_mode(no_progress: bool, quiet: bool) -> Mode {
    if quiet {
        Mode::Quiet
    } else if no_progress || !std::io::stderr().is_terminal() {
        Mode::Plain
    } else {
        Mode::Interactive
    }
}

pub struct Header {
    pub protocol: Protocol,
    pub destination: String,
    pub local_addr: Option<SocketAddr>,
    pub scenario: String,
    pub seed: u64,
}

impl Header {
    pub fn lines(&self) -> Vec<String> {
        vec![
            format!(
                "flowgen {} -> {} | scenario: {} | seed: {}",
                self.protocol.label(),
                self.destination,
                self.scenario,
                self.seed
            ),
            match self.local_addr {
                Some(addr) => format!(
                    "exporter source IP: {} (add it to Flowlink remote_addrs if you restrict senders)",
                    addr.ip()
                ),
                None => "dry run: flows are printed to stdout, nothing is sent".to_string(),
            },
            "note: Flowlink posts to the PCE every aggregation_minutes (default 10, min 5); expect that delay in Explorer".to_string(),
        ]
    }
}

pub struct Ui {
    mode: Mode,
    bar: Option<ProgressBar>,
    start: Instant,
    duration: Option<Duration>,
    stats_interval: Duration,
    last_plain: Instant,
}

impl Ui {
    pub fn start(mode: Mode, header: &Header, duration: Option<Duration>, stats_interval: Duration) -> Self {
        if mode != Mode::Quiet {
            for line in header.lines() {
                eprintln!("{line}");
            }
        }
        let bar = (mode == Mode::Interactive).then(|| make_bar(duration));
        let now = Instant::now();
        Self { mode, bar, start: now, duration, stats_interval, last_plain: now }
    }

    pub fn update(&mut self, stats: &Stats) {
        let elapsed = self.start.elapsed();
        match self.mode {
            Mode::Interactive => {
                if let Some(bar) = &self.bar {
                    if self.duration.is_some() {
                        bar.set_position(elapsed.as_millis() as u64);
                    }
                    bar.set_message(status_line(stats));
                }
            }
            Mode::Plain => {
                if self.last_plain.elapsed() >= self.stats_interval {
                    self.last_plain = Instant::now();
                    eprintln!("[{}] {}", fmt_elapsed(elapsed), status_line(stats));
                }
            }
            Mode::Quiet => {}
        }
    }

    /// Informational event (e.g. scan burst); hidden in quiet mode.
    pub fn notice(&self, msg: &str) {
        match (&self.bar, self.mode) {
            (Some(bar), _) => bar.println(msg),
            (None, Mode::Plain) => eprintln!("{msg}"),
            _ => {}
        }
    }

    /// Always shown, also in quiet mode.
    pub fn warn(&self, msg: &str) {
        let line = format!("flowgen: warning: {msg}");
        match &self.bar {
            Some(bar) => bar.println(line),
            None => eprintln!("{line}"),
        }
    }

    pub fn finish(self, stats: &Stats, rule_names: &[String]) {
        if let Some(bar) = &self.bar {
            bar.finish_and_clear();
        }
        eprintln!("{}", summary(stats, rule_names, self.start.elapsed()));
    }
}

fn make_bar(duration: Option<Duration>) -> ProgressBar {
    let bar = match duration {
        Some(d) => {
            let bar = ProgressBar::new(d.as_millis() as u64);
            bar.set_style(
                ProgressStyle::with_template(
                    "{spinner:.green} [{elapsed_precise}] {wide_bar:.cyan/blue} {percent:>3}%  eta {eta}\n  {msg}",
                )
                .expect("valid progress template")
                .progress_chars("=> "),
            );
            bar
        }
        None => {
            let bar = ProgressBar::new_spinner();
            bar.set_style(
                ProgressStyle::with_template("{spinner:.green} [{elapsed_precise}] {msg}")
                    .expect("valid spinner template"),
            );
            bar
        }
    };
    bar.set_draw_target(ProgressDrawTarget::stderr());
    bar.enable_steady_tick(Duration::from_millis(250));
    bar
}

pub fn status_line(s: &Stats) -> String {
    format!(
        "rate {:.0}/s (target {:.0})  flows {}  pkts {}  errs {}  scans {}",
        s.measured_rate(),
        s.target_rate,
        thousands(s.flows),
        thousands(s.datagrams),
        thousands(s.send_errors),
        s.scan_bursts
    )
}

pub fn summary(s: &Stats, rule_names: &[String], elapsed: Duration) -> String {
    let secs = elapsed.as_secs_f64();
    let avg = if secs > 0.0 { s.flows as f64 / secs } else { 0.0 };
    let share = |n: u64| if s.flows > 0 { n as f64 * 100.0 / s.flows as f64 } else { 0.0 };
    let width = rule_names.iter().map(String::len).chain([7]).max().unwrap_or(7);

    let mut out = format!(
        "\nsummary: ran {}  flows {}  pkts {}  bytes {}  avg {:.1} flows/s  send errors {}  scan bursts {}\n",
        fmt_elapsed(elapsed),
        thousands(s.flows),
        thousands(s.datagrams),
        thousands(s.wire_bytes),
        avg,
        thousands(s.send_errors),
        s.scan_bursts
    );
    out.push_str(&format!("  {:<width$}  {:>12}  {:>6}\n", "rule", "flows", "share"));
    for (name, &n) in rule_names.iter().zip(&s.per_rule) {
        out.push_str(&format!("  {:<width$}  {:>12}  {:>5.1}%\n", name, thousands(n), share(n)));
    }
    if s.scan_flows > 0 {
        out.push_str(&format!(
            "  {:<width$}  {:>12}  {:>5.1}%\n",
            "(scans)",
            thousands(s.scan_flows),
            share(s.scan_flows)
        ));
    }
    out
}

pub fn thousands(n: u64) -> String {
    let digits = n.to_string();
    let mut out = String::with_capacity(digits.len() + digits.len() / 3);
    for (i, c) in digits.chars().enumerate() {
        if i > 0 && (digits.len() - i) % 3 == 0 {
            out.push(',');
        }
        out.push(c);
    }
    out
}

pub fn fmt_elapsed(d: Duration) -> String {
    let t = d.as_secs();
    format!("{:02}:{:02}:{:02}", t / 3600, t / 60 % 60, t % 60)
}
```

```rust
//! The run loop: every tick, generate due flows, encode, and deliver them.

use std::io::{self, Write};
use std::net::{SocketAddr, UdpSocket};
use std::sync::atomic::{AtomicBool, Ordering};
use std::time::{Duration, Instant, SystemTime};

use anyhow::{Context, Result};

use crate::export::Encoder;
use crate::model::FlowRecord;
use crate::pattern::{Generator, Pacer, RateShape};
use crate::stats::Stats;
use crate::ui::Ui;

pub const TICK: Duration = Duration::from_millis(100);

pub enum Sink {
    Udp(UdpSocket),
    DryRun(Box<dyn Write>),
}

impl Sink {
    pub fn udp(dest: SocketAddr) -> Result<Self> {
        let socket = UdpSocket::bind(("0.0.0.0", 0)).context("cannot bind a local UDP socket")?;
        socket
            .connect(dest)
            .with_context(|| format!("cannot set up UDP to collector {dest}"))?;
        Ok(Sink::Udp(socket))
    }

    pub fn dry_run(out: Box<dyn Write>) -> Self {
        Sink::DryRun(out)
    }

    /// Local address used as exporter source (None for dry-run).
    pub fn local_addr(&self) -> Option<SocketAddr> {
        match self {
            Sink::Udp(socket) => socket.local_addr().ok(),
            Sink::DryRun(_) => None,
        }
    }

    /// UDP: send every datagram; failures are counted and the last one returned.
    /// Dry-run: print records; a write failure is returned as `Err`.
    pub fn deliver(
        &mut self,
        records: &[FlowRecord],
        datagrams: &[Vec<u8>],
        stats: &mut Stats,
    ) -> io::Result<Option<io::Error>> {
        match self {
            Sink::Udp(socket) => {
                let mut last_error = None;
                for dg in datagrams {
                    match socket.send(dg) {
                        Ok(n) => {
                            stats.datagrams += 1;
                            stats.wire_bytes += n as u64;
                        }
                        Err(e) => {
                            stats.send_errors += 1;
                            last_error = Some(e);
                        }
                    }
                }
                Ok(last_error)
            }
            Sink::DryRun(out) => {
                for r in records {
                    writeln!(out, "{}", r.dry_run_line())?;
                }
                out.flush()?;
                stats.datagrams += datagrams.len() as u64;
                stats.wire_bytes += datagrams.iter().map(|d| d.len() as u64).sum::<u64>();
                Ok(None)
            }
        }
    }
}

pub struct Engine {
    pub generator: Generator,
    pub shape: RateShape,
    pub encoder: Box<dyn Encoder>,
    pub sink: Sink,
}

impl Engine {
    /// Runs until `duration` elapses, `stop` is set, or dry-run stdout closes.
    pub fn run(
        &mut self,
        duration: Option<Duration>,
        stats: &mut Stats,
        ui: &mut Ui,
        stats_interval: Duration,
        stop: &AtomicBool,
    ) -> Result<()> {
        let start = Instant::now();
        let mut pacer = Pacer::default();
        let mut last_t = 0.0;
        let mut next_tick = start;
        let mut last_error_log: Option<Instant> = None;

        loop {
            if stop.load(Ordering::Relaxed) {
                break;
            }
            let elapsed = start.elapsed();
            if duration.is_some_and(|d| elapsed >= d) {
                break;
            }
            let t = elapsed.as_secs_f64();
            let dt = t - last_t;
            last_t = t;

            let rate = self.shape.rate_at(t, self.generator.rng());
            stats.target_rate = rate;
            let now = SystemTime::now();

            let mut records = Vec::new();
            if self.generator.has_rules() {
                for _ in 0..pacer.due(rate, dt) {
                    let (rule, record) = self.generator.next_flow(now);
                    stats.per_rule[rule] += 1;
                    records.push(record);
                }
            }
            for burst in self.generator.due_scans(elapsed, now) {
                stats.scan_bursts += 1;
                stats.scan_flows += burst.flows.len() as u64;
                ui.notice(&format!("scan burst from {}: {} flows", burst.src, burst.flows.len()));
                records.extend(burst.flows);
            }

            if !records.is_empty() {
                stats.flows += records.len() as u64;
                let datagrams = self.encoder.encode(&records, now);
                match self.sink.deliver(&records, &datagrams, stats) {
                    Ok(None) => {}
                    Ok(Some(e)) => {
                        if last_error_log.is_none_or(|t| t.elapsed() >= stats_interval) {
                            last_error_log = Some(Instant::now());
                            ui.warn(&format!("send failed: {e} ({} errors so far)", stats.send_errors));
                        }
                    }
                    Err(e) if e.kind() == io::ErrorKind::BrokenPipe => break,
                    Err(e) => return Err(e).context("cannot write dry-run output"),
                }
            }

            stats.sample(Instant::now());
            ui.update(stats);

            next_tick += TICK;
            let now = Instant::now();
            if next_tick > now {
                std::thread::sleep(next_tick - now);
            } else {
                next_tick = now; // fell behind; don't try to catch up in a burst
            }
        }
        Ok(())
    }
}
```

```rust
//! Command-line interface.

use std::io::{self, BufWriter};
use std::path::PathBuf;
use std::sync::Arc;
use std::sync::atomic::{AtomicBool, Ordering};
use std::time::{Duration, SystemTime};

use anyhow::{Context, Result, anyhow};
use clap::{Args, Parser, Subcommand};

use crate::config::{Overrides, Scenario, resolve_collector};
use crate::export::{Protocol, new_encoder};
use crate::pattern::{Generator, IPS_LIMIT, RateShape, make_rng, scenario_hosts};

const VERSION: &str = concat!(env!("CARGO_PKG_VERSION"), " (", env!("FLOWGEN_GIT_HASH"), ")");

#[derive(Parser)]
#[command(name = "flowgen", version = VERSION, about = "NetFlow v5/v9 and IPFIX generator for Illumio Flowlink testing and demos")]
struct Cli {
    #[command(subcommand)]
    command: Command,
}

#[derive(Subcommand)]
enum Command {
    /// Generate flows and send them to a collector (or print them with --dry-run)
    Run(RunArgs),
    /// List built-in presets, or print one as TOML
    Presets {
        /// Print the preset's scenario TOML
        #[arg(long, value_name = "NAME")]
        show: Option<String>,
    },
    /// Print every host IP a scenario can emit (for creating unmanaged workloads)
    Ips {
        #[command(flatten)]
        source: Source,
        /// List even if the scenario covers more than 4096 hosts
        #[arg(long)]
        all: bool,
    },
}

#[derive(Args)]
#[group(required = true, multiple = false)]
struct Source {
    /// Scenario TOML file
    #[arg(short = 'c', long = "config", value_name = "FILE")]
    config: Option<PathBuf>,
    /// Built-in preset name (see `flowgen presets`)
    #[arg(long, value_name = "NAME")]
    preset: Option<String>,
}

#[derive(Args)]
struct RunArgs {
    #[command(flatten)]
    source: Source,
    /// Collector HOST[:PORT]; port defaults to 2055 (v5/v9) or 4739 (ipfix)
    #[arg(long)]
    collector: Option<String>,
    /// Export protocol
    #[arg(long, value_enum)]
    protocol: Option<Protocol>,
    /// Base flows per second
    #[arg(long)]
    rate: Option<f64>,
    /// Stop after this long (e.g. 30s, 10m, 1h); default: run until Ctrl-C
    #[arg(long, value_parser = humantime::parse_duration)]
    duration: Option<Duration>,
    /// RNG seed for reproducible traffic
    #[arg(long)]
    seed: Option<u64>,
    /// Print flows to stdout instead of sending
    #[arg(long)]
    dry_run: bool,
    /// Plain periodic stats lines instead of a progress bar
    #[arg(long)]
    no_progress: bool,
    /// Only print warnings and the final summary
    #[arg(long)]
    quiet: bool,
}

pub fn main() -> Result<()> {
    match Cli::parse().command {
        Command::Run(args) => run(args),
        Command::Presets { show } => presets(show),
        Command::Ips { source, all } => ips(&source, all),
    }
}

fn load(source: &Source) -> Result<(Scenario, String)> {
    match (&source.config, &source.preset) {
        (Some(path), _) => Ok((Scenario::from_file(path)?, path.display().to_string())),
        (None, Some(name)) => {
            let preset = find(name).ok_or_else(|| {
                let names: Vec<&str> = PRESETS.iter().map(|p| p.name).collect();
                anyhow!("unknown preset '{name}' (available: {})", names.join(", "))
            })?;
            Ok((Scenario::from_toml(preset.toml)?, format!("preset {name}")))
        }
        (None, None) => unreachable!("clap requires --config or --preset"),
    }
}

fn run(args: RunArgs) -> Result<()> {
    let (mut scenario, label) = load(&args.source)?;
    scenario.apply(&Overrides {
        collector: args.collector.clone(),
        protocol: args.protocol,
        rate: args.rate,
        seed: args.seed,
    });
    let warnings = scenario.validate()?;
    let mode = ui::pick_mode(args.no_progress, args.quiet);
    for w in &warnings {
        eprintln!("flowgen: warning: {w}");
    }

    let protocol = scenario.target.protocol;
    let (sink, destination) = if args.dry_run {
        (Sink::dry_run(Box::new(BufWriter::new(io::stdout()))), "dry-run (stdout)".to_string())
    } else {
        let spec = scenario.target.collector.as_deref().context(
            "no collector: set [target].collector or pass --collector HOST[:PORT] (or use --dry-run)",
        )?;
        let addr = resolve_collector(spec, protocol)?;
        (Sink::udp(addr)?, addr.to_string())
    };

    let (rng, seed) = make_rng(scenario.seed);
    let generator = Generator::new(&scenario, rng)?;
    let rule_names = generator.rule_names().to_vec();
    let header = Header {
        protocol,
        destination,
        local_addr: sink.local_addr(),
        scenario: scenario.name.clone().unwrap_or(label),
        seed,
    };
    let mut engine = Engine {
        generator,
        shape: RateShape::new(&scenario.rate),
        encoder: new_encoder(protocol, &scenario.target.encoder_options(), SystemTime::now()),
        sink,
    };

    let stop = Arc::new(AtomicBool::new(false));
    {
        let stop = stop.clone();
        ctrlc::set_handler(move || stop.store(true, Ordering::Relaxed))
            .context("cannot install Ctrl-C handler")?;
    }

    let stats_interval = Duration::from_secs(scenario.stats_interval_secs);
    let mut ui = Ui::start(mode, &header, args.duration, stats_interval);
    let mut stats = Stats::new(rule_names.len());
    let result = engine.run(args.duration, &mut stats, &mut ui, stats_interval, &stop);
    ui.finish(&stats, &rule_names);
    result
}

fn presets(show: Option<String>) -> Result<()> {
    match show {
        Some(name) => {
            let preset = find(&name).ok_or_else(|| anyhow!("unknown preset '{name}'"))?;
            print!("{}", preset.toml);
        }
        None => {
            for p in PRESETS {
                println!("{:<12} {}", p.name, p.description);
            }
        }
    }
    Ok(())
}

fn ips(source: &Source, all: bool) -> Result<()> {
    let (scenario, _) = load(source)?;
    scenario.validate()?;
    let limit = if all { None } else { Some(IPS_LIMIT) };
    for ip in scenario_hosts(&scenario, limit)? {
        println!("{ip}");
    }
    Ok(())
}
```

```sh
# flowgen installer: picks the right release tarball for this OS/arch,
# verifies its SHA256 and installs the binary.
#
#   curl -fsSL https://github.com/OWNER/REPO/releases/latest/download/install.sh | sh
#   sh install.sh --from ./dist --prefix ~/.local/bin
set -eu

# Replaced with the real "owner/repo" by the release workflow.
REPO="${FLOWGEN_REPO:-__GITHUB_REPOSITORY__}"
VERSION="latest"
FROM=""
PREFIX="/usr/local/bin"

usage() {
  cat <<EOF
Usage: install.sh [--version vX.Y.Z] [--from DIR_OR_URL] [--prefix DIR]

  --version  release tag to install (default: latest)
  --from     directory or base URL that holds the release files
  --prefix   install directory (default: /usr/local/bin)
EOF
}

die() {
  echo "install.sh: $*" >&2
  exit 1
}

while [ $# -gt 0 ]; do
  case "$1" in
    --version) VERSION="${2:?--version needs a value}"; shift 2 ;;
    --from) FROM="${2:?--from needs a value}"; shift 2 ;;
    --prefix) PREFIX="${2:?--prefix needs a value}"; shift 2 ;;
    -h | --help) usage; exit 0 ;;
    *) usage >&2; die "unknown option: $1" ;;
  esac
done

os=$(uname -s)
arch=$(uname -m)
case "$os" in
  Linux)
    case "$arch" in
      x86_64 | amd64) platform=linux-x86_64 ;;
      aarch64 | arm64) platform=linux-aarch64 ;;
      *) die "unsupported Linux architecture: $arch" ;;
    esac ;;
  Darwin) platform=macos-universal ;;
  *) die "unsupported OS: $os" ;;
esac

if [ -n "$FROM" ]; then
  base="$FROM"
else
  case "$REPO" in
    __*) die "no release repository configured; use --from DIR or set FLOWGEN_REPO=owner/repo" ;;
  esac
  if [ "$VERSION" = latest ]; then
    base="https://github.com/$REPO/releases/latest/download"
  else
    base="https://github.com/$REPO/releases/download/$VERSION"
  fi
fi

tmp=$(mktemp -d)
trap 'rm -rf "$tmp"' EXIT

fetch() {
  case "$base" in
    http://* | https://*) curl -fsSL "$base/$1" -o "$tmp/$1" ;;
    *) [ -f "$base/$1" ] && cp "$base/$1" "$tmp/$1" ;;
  esac
}

sha256() {
  if command -v sha256sum >/dev/null 2>&1; then
    sha256sum "$1" | awk '{print $1}'
  else
    shasum -a 256 "$1" | awk '{print $1}'
  fi
}

suffix="-$platform.tar.gz"
file=""
have_sums=no
if fetch SHA256SUMS 2>/dev/null; then
  have_sums=yes
  file=$(awk -v s="$suffix" '{ f = $2; sub(/^\*/, "", f); if (length(f) > length(s) && substr(f, length(f) - length(s) + 1) == s) { print f; exit } }' "$tmp/SHA256SUMS")
else
  case "$base" in
    http://* | https://*) die "cannot download $base/SHA256SUMS" ;;
  esac
  for candidate in "$base"/flowgen-*"$suffix"; do
    [ -f "$candidate" ] && file=$(basename "$candidate") && break
  done
fi
[ -n "$file" ] || die "no flowgen package for $platform in $base"

fetch "$file" || die "cannot get $base/$file"

if [ "$have_sums" = yes ]; then
  expected=$(awk -v f="$file" '{ g = $2; sub(/^\*/, "", g); if (g == f) { print $1; exit } }' "$tmp/SHA256SUMS")
  actual=$(sha256 "$tmp/$file")
  [ "$expected" = "$actual" ] || die "checksum mismatch for $file"
fi

tar -xzf "$tmp/$file" -C "$tmp"
dir="${file%.tar.gz}"
[ -f "$tmp/$dir/flowgen" ] || die "archive $file has no flowgen binary"

use_sudo=no
if ! mkdir -p "$PREFIX" 2>/dev/null || [ ! -w "$PREFIX" ]; then
  command -v sudo >/dev/null 2>&1 || die "$PREFIX is not writable and sudo is not available; use --prefix"
  use_sudo=yes
fi

as_root() {
  if [ "$use_sudo" = yes ]; then sudo "$@"; else "$@"; fi
}

as_root mkdir -p "$PREFIX"
as_root install -m 0755 "$tmp/$dir/flowgen" "$PREFIX/flowgen"
if [ "$os" = Darwin ]; then
  as_root xattr -d com.apple.quarantine "$PREFIX/flowgen" 2>/dev/null || true
fi

echo "installed $PREFIX/flowgen"
"$PREFIX/flowgen" --version
```

````markdown
# flowgen

Generate NetFlow v5, NetFlow v9 and IPFIX traffic for testing and demoing **Illumio Flowlink**.
Single static binary, Linux and macOS.

## Install

**Script (Linux/macOS):**
```sh
curl -fsSL https://github.com/<owner>/<repo>/releases/latest/download/install.sh | sh
# or into your home dir:
curl -fsSL https://github.com/<owner>/<repo>/releases/latest/download/install.sh | sh -s -- --prefix ~/.local/bin
```

**Private repository:** download with the GitHub CLI, then install locally:
```sh
gh release download --repo <owner>/<repo> --dir flowgen-dist
sh flowgen-dist/install.sh --from flowgen-dist
```

**Packages:** `.deb` (`sudo dpkg -i flowgen_<ver>_amd64.deb`), `.rpm` (`sudo rpm -i flowgen-<ver>-1.x86_64.rpm`), macOS `.pkg` (double-click).

**macOS note:** binaries are not signed. For the tarball: `xattr -d com.apple.quarantine /usr/local/bin/flowgen` (install.sh does this). For the `.pkg`: right-click → Open.

## Quick start

```sh
flowgen presets                                   # list built-in scenarios
flowgen run --preset three-tier --dry-run --duration 10s
flowgen run --preset three-tier --collector flowlink.lab            # IPFIX to :4739
flowgen run --preset scan-demo --collector 10.0.0.5:2055 --protocol v9 --duration 30m
flowgen run -c my-scenario.toml --rate 500 --seed 42
```

Progress bar and live stats in a terminal; `--no-progress` for plain log lines, `--quiet` for summary only.
Ctrl-C stops gracefully and prints a summary.

## Making flows visible in the PCE

1. **Matching Flowlink listener.** v5/v9 need a `netflow` parser, IPFIX an `ipfix` parser on the port you send to:
   ```yaml
   consumers:
     - name: netflow
       parser:
         type: netflow
       connectors:
         - type: udp
           properties:
             ports: '2055'
     - name: ipfix
       parser:
         type: ipfix
       connectors:
         - type: udp
           properties:
             ports: '4739'
   ```
   Some Flowlink doc examples use `destinations:` instead of `consumers:` — check `/usr/local/illumio/flowlink_config_schema.json` on your Flowlink host.
2. **Exporter allow-list.** If Flowlink sets `remote_addrs`, add the "exporter source IP" flowgen prints at start.
3. **Workloads for the IPs.** The PCE shows Flowlink flows only when at least one IP of a flow is a managed or unmanaged workload. `flowgen ips --preset three-tier` lists every IP a scenario can emit.
4. **Wait one aggregation interval.** Flowlink posts to the PCE every `aggregation_minutes` (default 10, minimum 5).

## Scenario files

See [`examples/scenario.toml`](examples/scenario.toml) for every option with comments. Reference:

| Key | Meaning | Default |
|-----|---------|---------|
| `seed` | RNG seed | random (printed at start) |
| `stats_interval_secs` | plain stats line interval | 10 |
| `[target] collector` | `host[:port]` | — (required unless `--collector` / `--dry-run`) |
| `[target] protocol` | `v5` \| `v9` \| `ipfix` | `ipfix` |
| `[target] observation_domain` | v9 source id / IPFIX domain | 1 |
| `[target] template_refresh_secs` | template resend interval (also every 100 packets) | 30 |
| `[target] max_datagram` | max UDP payload bytes (256–65000) | 1400 |
| `[rate] flows_per_sec` | base rate | 100 |
| `[rate] shape` | `constant` \| `sine` \| `burst` | `constant` |
| `[rate] period_secs`, `amplitude` | sine wave | 300, 0.5 |
| `[rate] burst_chance`, `burst_multiplier`, `burst_secs` | random bursts | 0.05, 5, 10 |
| `[[rule]] name, src, dst, proto, dst_ports, weight` | weighted traffic rule (CIDRs or bare IPs) | weight 1 |
| `[[rule]] packets`, `bytes_per_packet` | `[min, max]` ranges | by protocol |
| `[[scan]] src, dst, ports, every_secs, flows_per_burst` | port scan bursts | every 120 s, 200 flows |

Multicast ranges (224.0.0.0/4) are rejected because Flowlink ignores them. Rates above 5000 flows/s produce a warning.

## Troubleshooting

- Nothing arrives: run Flowlink with `illumio-flowlink-ctl start --config <file> --debug` to print incoming records; check UDP reachability/firewalls; confirm protocol ↔ parser type on that port.
- `send failed: Connection refused`: nothing listens on the collector port (ICMP port unreachable).
- See exactly what would be sent: `--dry-run` (stdout, pipeable: `flowgen run --preset datacenter --dry-run | head`).
````
